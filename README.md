# OpenHC

**开源的 HiCar 车机端。** 装在安卓车机上，华为手机用数据线或无线投屏到车机屏幕。

[报告问题](https://github.com/GGBondLab/OpenHC/issues) · [从源码构建](#构建)

## 0.0.1 — 早期开发版

装在**车机**上，不是手机上。不需要 root、ADB、系统签名，不依赖车机自带的 HiCar，不用注册账号，不连任何服务器。
车机要允许安装 APK。

- **有线**：USB 数据线，车机安卓 6.0 起。
- **无线**：车机开热点，手机扫码连接，车机安卓 8.0 起。
- **手机**：带 HiCar 的华为或荣耀手机。有线连接时，手机要关闭「USB 调试」。

## 功能

- 画面：帧率自动跟随车机屏幕刷新率；清晰度三档可选；可全屏，也可保留车机底部导航栏。
- 触摸：多指操作，地图可以双指缩放。
- 声音：音乐和导航播报分开，导航播报走车机的导航音量。
- 方向盘按键：上一首、下一首、播放 / 暂停。
- 免码回连：第一次输入车机上显示的连接码，之后不用再输。
- 无线自动回连：手机靠近车机会自己发现车机；可选「手机蓝牙一连上车机就开始等手机」。
- 可选：插线时不再弹授权框、开机自动打开、无线结束后恢复车机 WiFi。

## 使用

1. 车机安装 OpenHC。
2. **有线**：首页点「开始」，手机插车机 USB 口，在手机上点「连接」，第一次输入车机显示的连接码。
3. **无线**：首页「无线连接」点「开始」，手机扫车机上的二维码。之后手机靠近车机会弹出「发现车机」。

## 状态

早期开发，还没发布安装包。有线、无线投屏已在一台安卓 10 车机和一部鸿蒙系统的华为手机上验证。

已知限制：

- 用过车机自带 HiCar 或同类应用的手机，第一次连 OpenHC 可能失败：在手机 HiCar 里删掉旧的车机记录，再扫码连接。
- 无线开着时车机一直开着热点，车机自己的 WiFi 会断开；结束后安卓 10 起的车机可能要手动打开 WiFi。
- 手机和车机断开不到约 10 分钟时，手机不会自动回连，会弹「发现车机」，需要点一下。
- 通话和车机麦克风还没有验证。

## 构建

需要 JDK 17 和 Android SDK 36：

```sh
./gradlew check assembleDebug
```

安装包在 `app/build/outputs/apk/debug/`。代码结构见 [架构说明](docs/ARCHITECTURE.md)。
