# OpenHC

**面向安卓车机与大屏设备的开源投屏接收端（个人学习与社区维护分支）。**

本项目为非商业开源技术研究与个人兴趣维护分支，基于上游 **[GGBondLab/OpenHC](https://github.com/GGBondLab/OpenHC)** 持续演进。完全本地运行、无需 Root、无需账号，不连接任何第三方服务器，仓库内**不包含任何厂商代码、私有密钥或连接凭据**（详见 [安全说明](SECURITY.md)）。

## 本分支的优化方向

在上游原版扎实架构的基础上，本分支主要围绕**日常使用的流畅度、界面观感与多形态大屏交互**做了持续打磨：

- **极简座舱界面与昼夜自适应**：重构深色石墨 / 浅色纯白两套中性配色，支持随系统昼夜模式自动切换；横屏下采用双栏首页与全高分栏设置页，信息层级更清晰，减少视觉干扰。
- **音视频传输与播放体验优化**：引入控制 / 音频优先的协议双车道调度、零分配热路径与低延迟网络锁；优化音频抖动缓冲与异常恢复策略，改善网络短暂波动后的突发快放与偶发断流问题。
- **无触屏大屏与遥控器兼容**：补充 TV 桌面入口与非触屏硬件声明，首页自动落焦，全应用交互控件配备遥控器专属焦点高亮，修复输入框方向键脱离问题，并支持在日志窗口内用方向键翻阅。
- **自启与回连体验打磨**：完善冷启动拉起与回连等待衔接，优化相关权限与系统设置状态的直观提示。
- **内置实时诊断日志**：将车机端实时滚动日志与一键导出整合在「设置 → 诊断」同一界面，自动对设备地址脱敏，方便无电脑环境下自行排查异常。
- **轻量化构建与自动化检查**：通过 R8 裁剪减小安装包体积，配合自动化测试与 API 23 兼容性检查保障每次改动稳定可靠。

## 运行环境

本应用安装在**车机或安卓大屏端**（非手机端），需允许安装第三方 APK。日常使用不需要 Root 与系统签名，也不依赖外部 ADB（仅部分可选辅助开关默认关闭）。

- **系统要求**：有线模式支持 Android 6.0 及以上；无线模式建议 Android 8.0 及以上。
- **连接方式**（设置 → 连接方式）：
  - **本地热点（默认）**：免手动配置，连接期间自动建立本地通信网络。
  - **设备自带热点**：连接更稳定，可减少后台扫网与频段干扰，需提前配置热点名称、密码与频段。
  - **Wi-Fi 直连**：尝试保留设备原有 Wi-Fi 连接，具体可用性取决于系统与硬件支持情况。

## 主要能力

- **显示适配**：帧率自动匹配屏幕刷新率，提供清晰度档位、投屏界面缩放及全屏 / 保留导航栏选项。
- **交互控制**：支持多指触控与常见媒体按键映射，兼顾触屏车机与遥控器大屏操作。
- **多路音频输出**：支持媒体与导航语音分流，可按需选择输出声道并直接在设置页试听。
- **便捷体验**：支持配对记忆、自动回连、有线优先接入及可选的开机启动与网络恢复。

## 基本使用

1. 前往 [Releases](https://github.com/DongShull/OpenHC/releases) 获取安装包并安装到目标设备。
   > 若此前安装过上游原版或其他社区分支，因构建签名不同，首次切换请先卸载旧版。
2. 首次启动时按系统提示授予蓝牙、附近设备 / 位置等必要运行时权限。
3. **无线使用**：首页点击「开始连接」，按界面指引完成首次扫码与配对；后续在满足条件时可自动回连。
4. **有线使用**：打开应用并通过数据线连接设备（未处于无线连接时插线优先）。
5. **可选自启设置**：Android 10 及以上系统如需后台拉起界面，请在「设置 → 启动」中按引导开启悬浮窗权限及系统自启动放行。

## 常见问题

<details>
<summary><b>1. 首次配对失败或提示配对信息异常</b></summary>

- 若手机此前与车机内置互联服务或同类应用配对过，建议先在手机端清理旧配对记录，并关闭车机系统自带的同类互联开关后再试。
</details>

<details>
<summary><b>2. 无线连接偶发卡顿或音频波动</b></summary>

- 优先尝试「设备自带热点（5 GHz）」以减少 2.4 GHz 蓝牙共存干扰与后台 Wi-Fi 扫描影响。
- 如问题可复现，可在「设置 → 诊断 → 实时日志」点击「导出」，附上脱敏日志反馈排查。
</details>

<details>
<summary><b>3. 无法读取设备蓝牙地址</b></summary>

- 部分车机或安卓大屏限制读取系统蓝牙地址，可在「设置 → 连接方式 → 车机蓝牙地址」手动填写设备真实地址（支持遥控器方向键直接操作）。
</details>

<details>
<summary><b>4. 老版本系统或其他社区分支参考</b></summary>

- 本分支主要面向 Android 8.0 及以上设备持续维护；如需适配更早期的安卓版本或特定系统组合，也可参考社区内其他开源维护仓库：
  - [LinkeZhang/OpenHC](https://github.com/LinkeZhang/OpenHC/releases)
  - [hicar-android-receiver](https://github.com/huducat586/hicar-android-receiver)
</details>

## 问题反馈

如遇到异常，请先在应用内打开 **「设置 → 诊断 → 实时日志 → 导出」**（Android 10+ 位于 `下载/OpenHC/`，更早系统位于应用外部私有目录，已自动遮蔽完整设备地址且不含密钥），随后在 [Issues](https://github.com/DongShull/OpenHC/issues) 中说明设备系统版本、操作步骤并附上日志。

安全原则与隐私边界详见 [SECURITY.md](SECURITY.md)。

## 从源码构建

需要 **JDK 17** 与 **Android SDK 36**：

```sh
./gradlew check assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/`，模块划分与设计说明见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

- 本公开源码库不包含任何私有连接参数文件；开发者如需自行调试完整互联流程，请参考 [docs/identity.example.json](docs/identity.example.json) 自行准备本地配置文件并在构建环境中指定路径。
- 欢迎符合本仓库开源规范与 [GPL-3.0](LICENSE) 协议的改进建议与 Pull Request（请勿提交任何反编译代码、私有密钥或真实设备抓包数据）。
